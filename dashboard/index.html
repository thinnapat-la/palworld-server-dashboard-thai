ส่วนนี้กำหนดเวลาและข้อความสำหรับปุ่ม Restart Server เท่านั้น ระบบจะล็อก Config ล่าสุดก่อนหยุด Server เขียนไฟล์เดิมกลับหลังหยุดสนิท แล้วตรวจ GET /settings หลังเปิดใหม่ ค่าร่างต้องกด อัปเดตไฟล์ ก่อน
